## Featured Projects

### 1. Indian Traffic Sign Recognition — YOLO-based Computer Vision

[**View Repository**](https://github.com/Param-Sahu/Indian_Traffic_Sign_Recognition)

Developing a traffic sign recognition vision model for Advanced Driver Assistance Systems (ADAS), using fine-tuned YOLO architectures and a custom Indian traffic sign dataset aligned with **IRC:67-2022** standards. The research explores temporal filtering to improve prediction stability in real-world driving scenarios.

**Technologies:** Python, YOLO, OpenCV, Computer Vision, Deep Learning

### 2. Academic Sheet Automation Program (ASAP)

[**View Repository**](https://github.com/Param-Sahu/Academic-Sheet-Automation-Program)

Developed a Python desktop application to consolidate student and semester data from multiple Excel files into a structured CSV for academic result processing and digital marksheet generation. Deployed for departmental use at my college to reduce manual work and data entry errors.

**Technologies:** Python, Pandas, Tkinter, PyInstaller, Excel Automation

### 3. Election Exit Poll and Voter Prediction Model

[**View Repository**](https://github.com/Param-Sahu/Exit_Poll_and_Vote_Prediction_Model)

Built a machine learning classification workflow to analyze demographic and opinion-based variables, compare multiple classification algorithms, and predict voting preferences. Deployed the selected model through a Streamlit application for interactive predictions.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Streamlit, Data Analysis

### 4. Face Recognition-Based Attendance System

[**View Repository**](https://github.com/Param-Sahu/Face_Recognition_Based_Attendance_System)

Developed a face recognition application that captures webcam video, identifies registered faces, and records attendance in Google Sheets for convenient access and tracking.

**Technologies:** Python, OpenCV, Face Recognition, Google Sheets API

### 5. Data Engineering — Competitor Price Monitoring

Built an automated competitor product price-monitoring solution for a US-based manufacturing client, collecting product details and pricing data from seven e-commerce websites. Designed automated web scraping, product URL synchronization, and scheduled ELT workflows in Microsoft Fabric, with standardized Silver-layer datasets for downstream analytics and reporting.

**Technologies:** Python, Microsoft Fabric, PySpark, Spark SQL, Lakehouse, Delta Tables, Medallion Architecture, BeautifulSoup, REST APIs

*This project was developed professionally; source code is not linked here.*

### 6. Snowflake ELT Pipeline

Built an automated ELT pipeline integrating Azure Blob Storage with Snowflake. Used Snowpipe, Streams, and Tasks for ingestion and incremental processing, with Medallion Architecture for data transformation and analytics-ready datasets.

**Technologies:** Python, SQL, Snowflake, Snowpipe, Streams, Tasks, Azure Blob Storage

*This project was developed during my ML internship.*
